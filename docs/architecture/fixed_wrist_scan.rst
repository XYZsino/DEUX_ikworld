준비자세 손목 고정 스캔 (2026-10-26)
==================================

사용자 선택: 준비자세에서 스캐너를 들고 있는 손목 각도를 유지한다.
이동 중 스캐너 약13도 기울어짐은 허용하고 우선 시나리오로 확인한다.

구현
----

head_calibration.yaml barcode_fixed_wrist로 왼팔 말단 arm_l_joint5/6/7을
준비 목표 [-0.8003885081,-0.0567193044,-0.6648923480]rad에 고정한다.
약 [-45.859,-3.250,-38.096]도이며, 손목을0도로 펴는 방식은 아니다.
1~4번 관절만 사용해 관측된 바코드로 리더를 조준한다. 오른팔과 손가락 목표는 유지한다.

ROS reader frame +Z가 전방이고 body-up은 -X다. MuJoCo 광학 site의 -Z 전방과
혼동하지 않는다. reader_alignment.py는 전방 조준/바코드 앞면/거리/몸체 위쪽을
함께 고려한다. 거리6~24cm(선호 최소8cm), 조준오차3도 이내, pitch/skew55도 이내,
도착 기울기5도 이내, 이동 중15도 이내를 검사한다. 약13도 허용 요청을 반영한
수치 여유이며 이번 실제 경로의 최대값은12.8도다.

손목 고정 상태로 도달하지 못하면 실패하며 자유 손목 IK로 자동 전환하지 않는다.
계획 시작 관절값은 준비 목표에서0.03rad 이내여야 한다. 손목 목표를 유지하며
일반 관절 보간을 사용한다. 별도의 자세 보정 경유점은 추가하지 않았다.
Planner와 execution_node 모두 명령 경로의 손목/기울기를 검사한다.
AlignBarcode 실행 중 측정 관절의 손목/기울기도 감시한다. 관절/충돌 검사는 유지한다.

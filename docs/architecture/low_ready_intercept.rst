낮춘 준비자세와 예측 접근
=======================

사용자 요청: 기본자세에서 봉투와 접촉하지 않는 범위로 손을 낮춰 접근 경로를
줄이고, 물체 이동을 예측해 접근한 다음 추종·파지한다.

설정
----

``src/deux_task_sim/deux_task_sim/head_calibration.yaml``이 현재 영상 기반 sim의
기본 자세와 파지 설정입니다. 원래 오른손 EE 대비 base_link 기준 X+74.1mm,
Y+149.8mm, Z-73.6mm로 파지 영역 가까이에 배치했습니다. 손목 방향 변화는
약0.30°입니다. 원래 XYZ는 [0.389020,-0.350069,0.961950]m,
새 XYZ는 [0.463168,-0.200226,0.888353]m입니다. 왼팔/리더 기준은 유지합니다.

준비 중 오른손을 hand_open 값으로 미리 엽니다. 열린 손 mesh 최저점과 sim
봉투 최고점의 수직 차이는34.9mm입니다. 이 값은 sim 모델의 기하 검사이며
실제 봉투 크기/변형과 실제 장착/로봇 캘리브레이션의 보증은 아닙니다.
원래 준비관절 기준은 ready_pose.HOME_JOINTS에 그대로 보존합니다.

동작 순서
---------

1. Prepare: 기존 팔꿈치 굽힘 경유점을 통과해 낮춘 자세로 이동, 손 미리 열기.
2. 준비 동작 중에도 ZED 영상에서 아직 파지 영역에 도달하지 않은 상류 물체를
   선택해 ICP/Kalman 속도를 미리 추정. 이미 파지 영역 안에 들어온 물체를
   준비 시작 때 선택해 뒤늦게 쫓지 않음. TrackAndSelect / EstimatePose는
   준비 완료 후 대상과 신선도/속도 안정화를 다시 확인. 준비 팔에 가려 이미지
   ID가 사라지면 준비 중에만 다시 선택하며, 접근 시작 후에는 대상 ID를 바꾸지 않음. 사용자 확인 컨베이어 속도8cm/s는 Kalman의 초기 속도로만 사용하며, 이후
   관측으로 보정되는 속도로 계획. 실제 물체가5cm/s이면 그 속도로 수렴하는
   단위 시험도 포함.
3. Approach: 현재 물체 위치가 아닌 **예약 시작+접근시간 후의 위치** 위로 접근.
   상류 영역에서 시작할 수 있지만 예상 도착점은 파지 영역 안에 있어야 함.
4. 도착 이후 촬영된 새 관측을 기다림. 이전 접근의 포즈 snapshot은 재사용하지 않음.
5. TrackGrasp의 Track: 새 포즈로 재계산하고 물체 속도에 맞추는 이동.
6. Descend → Close: 속도를 이어가며7cm 하강 후 손 닫기. 마지막 제한된 감속 적용.
7. 기존 Lift와 영상 기반 파지 확인 단계로 진행. 성공 여부는 별도 센서 조건으로 판단.

기본 시간은 Approach1.5초, Track0.65초, Descend0.8초, Close1.8초입니다.
이는 보장 실행시간이 아니라 계획 시작값입니다. 관절 속도/가속도 검사 후
필요한 단계만 늘리며, 늘어난 시간에 맞춰 예상 위치와 영역 이탈을 다시 검사합니다.
예약 시작 여유0.4초, 접근 전 전체 영역 예측7초를 사용합니다.

실행 중 원 취득시각 기준 포즈 만료/편차/영역 감시는 유지합니다. 손을 연 Track
구간과 그 예약 시작 대기 중에만 마지막 관측에서 최대0.8초까지 예측할 수 있습니다.
Kalman의8×8 공분산과 추가 가속도 노이즈로 위치/방향 불확실성을 전파하며,
예상 위치 편차+2σ 반경이25mm를 넘거나 영역 여유를 침범하면 중단합니다.
관측 시각을 현재로 덮어쓰지 않고 execution_record에 예측 사용을 기록합니다.
하강·닫힘에는 이 예측 예외를 허용하지 않습니다. 공분산은 모델 가정에 기반하며
실측 정확도를 인증하지 않습니다. 실제 로봇에서는 별도 검증이 필요합니다.

state_observation_node는 새 포즈 수신 시 바로 전달하고 주기 타이머를 재설정해
중복 발행과 추가 대기를 줄입니다. 준비 중 이미지 ID가0.35초 이상 사라지면
다시 선택하지만, 접근 시작 후에는 다른 ID로 자동 전환하지 않습니다.

이 변경은 접근 뒤의 새 관측으로 재계획하는 방식이며 매 프레임 visual servo는
아닙니다. Track의 시작 속도는 두 IK 해를 차분하지 않고 로봇 Jacobian으로
계산합니다. 따라서 IK 잔차가 가짜 관절 속도로 확대되지 않습니다.

검증 자료
---------

기하 후보 검사: validation/head-rgbd/low-ready-probe/result.json.
최종 열린 준비손의 기하 검사: validation/head-rgbd/low-ready-near/result.json.
오프라인 기하/qpos는 검증 전용이며 ROS 제어 관측으로 사용하지 않습니다.

최신 검증 결과
-------------

``validation/head-rgbd/low-intercept-17``에서 실제 접근 EE 경로는19.98cm입니다.
기존 zed-moving-07의37.76cm 대비약47% 짧습니다. 두 실행은 도착 시각/지점도
다르므로 동일 endpoint의 성능 벤치마크가 아니라 기록된 시나리오의 경로 비교입니다.
접근 상태 소요 시간은2.516초 대2.380초로, 시간 단축 결과를 주장하지 않습니다.

기록된 손–봉투 최소 mesh 거리는 준비 완료 대기24.93cm, 접근3.28cm,
Track3.96cm입니다. 열린 준비 손의 전체 높이 범위와 봉투 최고점 사이 수직 여유는
별도 기하 검사에서34.9mm입니다. 해당 sim의 설비/물체 침투0, physics warning0,
weld0입니다. 저장 qpos 샘플 검사이며 연속 궤적 전체/실기 충돌 보증이 아닙니다.

Prepare0.102 → EstimatePose6.188 → Approach6.392 → TrackGrasp8.942 →
Track9.146초까지 진행했습니다.9.894초에 손가림으로 예측 불확실성과 편차의 합이
설정 여유를 넘어 정지했습니다. **하강·파지까지 정상 검증되지는 않았습니다.**
남은 문제는 부분가림 ICP 관측의 신뢰도와 연속성입니다. 허용 오차를 늘려
통과시키지 않았으며 실제 파지 성공으로 표시하지 않습니다.

같은 폴더의 dashboard-rgbd.html / scenario-rgbd.mp4에서 준비 자세 전후,
녹화 및 실제 ROS 메시지를 확인할 수 있습니다. clearance-path-audit.json에는
거리/경로 수치가 있으며 execution_record 이벤트는 원 취득시각9.010초를
유지한 채0.612~0.680초의 예측 추종 사용을 보여줍니다.

최종 ROS 2 빌드8패키지, 회귀 테스트108개 통과. 로그는
validation/head-rgbd/build-low-intercept-final17.log 및
validation/head-rgbd/regression-low-intercept-final17.log입니다.

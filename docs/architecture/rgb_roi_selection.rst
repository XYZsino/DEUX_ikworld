RGB ROI와 3D 박스 기반 대상 선택
================================

2026-10-27. 사용자 선택: 기존 오른손 대상 선택 영역을 RGB에 투영한 범위.

선택 규칙
---------

head_calibration.yaml의 target_selection_policy: rgb_roi_3d_bbox를 사용한다.
기존 conveyor_tracking.acquisition_region의 8개 모서리를 촬영 시각의 카메라 TF와
등록된 영상의 투영 행렬로 RGB에 투영한다. 투영 모서리를 감싸는 사각형을
화면 경계로 자른 것이 ROI이다. 카메라 뒤에 걸치거나 TF가 없으면 ROI를 사용하지 않는다.
임의의 새 카메라 외부 파라미터나 실기 보정값을 만들지 않았다.

다음 조건을 같은 RGB 프레임에서 만족하면 즉시 대상을 선택한다.

* 추적 ID가 있는 bread_bag 검출 박스의 중심이 ROI 안에 있다.
* 해당 대상의 분할 마스크와 등록된 depth로 유효한 3D 박스가 생성된다.
* 검출과 3D 후보의 sequence/촬영 시각/요청 ID가 일치하며 데이터가 최신이다.

3D 박스는 보이는 표면의 base-frame AABB이다. 전체 봉투 형상이나 ICP pose가 아니다.
마스크 경계를 침식하고 깊이 이상치를 제거한 뒤 2~98 percentile 범위를 사용한다.
최소 40개의 일관된 깊이 점, 유한한 크기, 최대 축 길이 60cm 이하 등의 형식 검사를 유지한다.
GUI 박스와 선택 증거가 같은 surface_bounds 함수를 사용한다.

기존 BT의 추가 신뢰도 0.5 조건, 3회 연속 검출, XYZ 중심의 acquisition_region 내 포함,
Prepare 중 upstream 영역에 한정한 선택 조건은 새 정책에서 제거했다.
YOLO 자체의 검출 임계값은 유지한다. 기본값은 0.25이며 별도 설정 가능하다.
명시적으로 지정한 대상 ID는 계속 존중한다.

여러 후보가 있으면 컨베이어 진행 방향을 따라 오른손 작업 영역을 통과하는 쪽을
우선하고, 같은 우선순위에서는 기존처럼 상류 대상을 고른다. 이것은 순위이며
옆 열의 물체도 유일한 후보이거나 사용자가 ID를 지정하면 선택 가능하다.
첫 SIM에서 옆 열의 봉투가 먼저 선택되어 접근 계획이 차단된 것을 확인한 후 이 순위를 보완했다.

선택과 실제 움직임의 구분
------------------------

한 프레임은 대상 선택과 ICP 요청을 시작하기에 충분하다.
EstimatePose는 유효한 ICP/Kalman 포즈와 속도를 확보한 뒤 접근을 요청한다.
현재 ICP의 velocity_valid는 최소 3회 측정 후 설정된다.
이전의 추가 6회 관측 조건, 별도 3회 속도 안정성 창, BT의 사전 도착/완료 영역 예측은
새 정책에서 생략한다. 원본 취득 시각·속도와 벨트 명령의 일치 검사는 유지한다.

플래너·실행기의 실제 도달 영역, 경로 예측, 충돌, 관절 제한, 추종 오차, 만료 검사는 유지한다.
따라서 ROI/3D 박스는 파지 시도를 시작하는 조건이며 임의의 위치에 실제 움직임을 보장하지 않는다.
2D 투영 영역 안에도 실제 오른손 작업 영역 밖 물체가 들어올 수 있고,
이 경우 접근 계획이 거부될 수 있다. 실패 사유는 기존 TaskStatus로 표시된다.

GUI 및 설정
-----------

ZED RGB에 노란색 Pick ROI를 선택 전부터 표시한다. 선택된 대상에는 기존 초록색
3D 박스를 표시한다. 오래된 프레임에 다른 프레임의 ROI/박스를 덧씌우지 않는다.

head_rgbd.launch.py는 perception_node에도 scene_config를 전달한다.
SIM과 실기 모두 같은 설치 파일의 target_selection_policy와 acquisition_region을 사용해야 한다.
설정이 없는 기존 설치는 legacy 선택 정책을 유지한다.
실기에서는 확인된 카메라 보정·작업 영역 설정이 필요하다.

DetectionArray에 selection_roi_valid/selection_roi_xyxy,
VisualEvidence에 bbox3d_valid/bbox3d_min/bbox3d_max 필드를 추가했다.
메시지 ABI 변경이므로 생산자·소비자를 함께 재빌드하고 재시작해야 한다.

가까운 컨베이어 세로 범위 보정
-----------------------------

사용자 정정에 따라 selection_roi_vertical_fraction: [0.55, 1.0]을 설정했다.
기존 투영 ROI의 좌우 범위는 유지하고 영상 세로의 55~100%를 사용한다.
현재 640×480 기준 ROI=[117.68,264,640,480]. 가까운 직선 컨베이어를 포함하고
먼 쪽 컨베이어를 제외한다. 일시적으로 적용했던 전체 높이 [0,1] 설정은 폐기했다.
실기 카메라 시야가 다르면 같은 설정값을 실제 영상에 맞춰 조정해야 한다.
7패키지 재빌드 및 실제 GUI RGB 표시 확인. 파지 동작을 추가로 실행하지 않았다.
